### My Component Library ꩜
## This library contains reusable components from my flower website.

### Components

## Logo (.site-logo): Displays my flower logo at the top of a page.

## Navigation (nav): Lets visitors move between the home, about, info, and gallery pages.

## Hero (.hero): Introduces a page with a heading, text, image, and quote.

## Flower Card (.flower-card): Displays a flower image, name, and information about the flower.

## Gallery (#gallery): Displays a collection of flower images.

## Survey Form (.form-v2): Collects visitors' flower preferences and survey answers.

## Footer (footer): Displays copyright information at the bottom of the page.

### Files

## components.html contains the reusable HTML components.

## styles/styles.css contains the components' CSS rules.

## images/ contains the images used by the components.

## index.html is the workspace for testing new components and variations.
